# supply-block-chain :truck: :chains:
Supply Chain Management application that uses a blockchain system to keep track of package status from origin to destination.

Codebase:
- Golang for core application functionality.
- Python for web application.

Technologies:
- MongoDB for database.
- Google authentication for user authentication.
